# proposal

> Material for the PlantForAdapt proposal

## Usage

**proposal** is based on the R code of `map.R` and the reproducible document `index.qmd`.

## Project

- Reproducible analyses in the quarto document `index.qmd`
- Map code in `map.R` and resulting `fig.png`
- html files (`index.html`, `index.index_files` , `authors_list_files` )
- R files (`proposal.Rproj`)
- Git files (`.gitignore`)
- Project documentation (`README.md`)
